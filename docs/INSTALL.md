# 安装

## 前置条件

- Emby Server 4.9.x。
- 使用服务器提供的 Emby Web。
- 播放器已安装，并已向操作系统注册对应 URL Scheme。
- 播放器可以访问 Emby 对外地址并信任其 HTTPS 证书。

当前仅在 macOS 完成实际验证，其他系统应先在非生产环境测试。

## 首次安装

1. 停止 Emby Server。
2. 从发布包中取出 `Emby.ExternalPlayer.dll`。
3. 把 DLL 放入 Emby 程序数据目录的 `plugins` 文件夹。
4. 启动 Emby，在插件列表中打开 `External Player`。
5. 启用需要的播放器，并检查其适用平台和平台默认值。
6. 强制刷新 Emby Web，打开一个本地视频详情页确认“外部播放”入口。

基础设置、票据有效期和内置播放器平台范围会在字段变化后自动保存。自定义播放器保留每条配置自己的保存和删除操作。

## 升级

1. 正常停止 Emby，让插件撤销 Web 加载片段并清空内存票据。
2. 替换 `plugins` 目录中的 DLL。
3. 启动 Emby 并强制刷新 Web。
4. 检查插件版本、配置页和一次实际播放。

## 禁用和卸载

关闭插件总开关会停止 API、清空票据并撤销 Web 入口。卸载时应正常停止 Emby 后再删除 DLL，避免跳过清理回调。

个人默认播放器保存在 Emby 配置目录的 `external-player-user-preferences.xml`，正常卸载会同时删除主文件、`.bak` 和严格匹配的临时文件。若日志提示清理失败，可在 Emby 完全停止后手动删除这些固定文件。

## 常见问题

- 插件列表中没有插件：检查服务器日志中的程序集加载错误，并确认服务器版本不低于 SDK 基线 4.9.1.80。
- 详情页没有入口：确认插件和 Web 入口均已启用、媒体源是本地 `File`，然后强制刷新 Web。
- 点击后无反应：确认应用已注册 URL Scheme，并允许浏览器打开外部应用。
- 播放器无法读取：确认播放器能直连 Emby 地址、证书可信，反向代理保留协议、Host、base path 和票据请求头。
- Emby 升级后入口消失：检查日志中的 Dashboard UI 锚点警告；插件不会修改未知结构。
