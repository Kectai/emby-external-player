| Emby Server | 插件加载 | Web 配置 | 播放清单与解析 | 媒体/字幕流 |
|---|---:|---:|---:|---:|
| 4.9.1.80 | 通过 | 通过 | 通过 | 通过 |
| 4.9.3.0 | 通过 | 通过 | 通过 | 通过 |
| 4.9.5.0 | 通过 | 通过 | 通过 | 通过 |

插件目标框架为 `netstandard2.1`，Emby SDK 编译基线固定为 4.9.1.80。

## 适用条件

- 使用服务器提供的 Emby Web。
- 媒体源为本地 `File`，或为 Emby 识别的静态 HTTP(S) `.strm`；远程源站需直接返回可供播放器访问的临时 HTTP(S) 重定向。字幕已经被 Emby 识别为本地外挂字幕。
- STRM 源 URL 或 Emby Container 应提供真实媒体格式。两者都无法识别时，启动路径会使用 `.mkv` 作为通用后缀；依赖 URL 后缀而不探测内容的播放器可能不兼容这类不透明下载入口。
- 重定向地址不依赖任何签名参数判断有效期。插件采用单一的 30 秒按需租约；租约到期后的下一次网关访问直接重新解析源站，Emby Server 不探测 CDN，也不返回过期地址。源站解析最长可能等待 30 秒；临时失败会返回带 `Retry-After` 的 503，并在短期退避后允许重试。为限制异常客户端或恶意请求对源站造成压力，同一源短时间内最多发起 12 次新远程操作，超过后会返回带 `Retry-After` 的 429；正常播放和 seek 不应触及该边界，连续快速拖动可能需要稍后重试。
- Emby Dashboard UI 没有稳定的官方按钮扩展接口；未知 Web 结构会使入口安全失效，而不会修改不认识的文件内容。
- 浏览器、操作系统和播放器都可能拦截或改变自定义协议行为，需要在目标环境人工确认。
